# V3.7 Contract Update

This update changes the GMINE miner to use V3.7 contracts, which include minimal fixes for staking and reward distribution.

## Contract Addresses

- **Mining Contract**: `inj14yywct7l4ts9tgqxm4vwe66lwuh5fc5sxplemm`
- **Power Token**: `inj139a7ev9yhq0lmrz408puguvc5xrfxvndmztrzw`

## What Changed in V3.7

V3.7 applies only 2 minimal fixes to the V3.5 codebase:

1. **Staking Field Fix**: Changed `lock_duration` to `lock_duration_blocks` to fix staking deserialization errors
2. **Reward Calculation Fix**: Fixed zero effective score bug that prevented reward distribution

## Files Updated

1. `src/config/mod.rs` - Default contract addresses
2. `src/chain/queries.rs` - Testnet contract addresses
3. `src/chain/messages/mod.rs` - Mining contract constant
4. `config.toml` - Configuration file contract addresses
5. `gmine_mobile_lib/src/blockchain_hybrid.rs` - Mobile library contract address

## How to Use

If you're using a custom config file, update the contract addresses:

```toml
contract_address = "inj14yywct7l4ts9tgqxm4vwe66lwuh5fc5sxplemm"
power_token_address = "inj139a7ev9yhq0lmrz408puguvc5xrfxvndmztrzw"
```

The miner will automatically use V3.7 contracts if no custom config is provided.
